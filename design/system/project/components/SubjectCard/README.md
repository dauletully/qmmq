# SubjectCard

Карточка предмета в блоке «Для кого»: иконка в цветной плашке, заголовок, 1–2 предложения; верхняя полоса 3 px цвета предмета.

## Правила

- Белая карточка на `surface-alt`, рамка `line`, радиус `radius-md`, отступ 24 px. Цвет предмета — только полоса сверху и плашка иконки 48 px (`subject-*-tint` + `subject-*`).
- Иконки Lucide 24 px, линия 1.5: `sigma` — математика, `atom` — физика, `code-xml` — информатика.
- 390: карточки столбиком, зазор 16 px. 1024+: три в ряд, одинаковой высоты.
- Текст до ~160 знаков; казахский длиннее на 20–30 % — карточка растёт вниз, а не обрезает.
- Не добавлять цветную полосу слева — только сверху.

## Что передаёт потребитель

`audience.cards[]`: `subject`, `title`, `text`.
