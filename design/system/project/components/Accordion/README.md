# Accordion

Раскрывающиеся строки для программы по дням (блок 4) и FAQ (блок 11): заголовок-кнопка во всю ширину, круглый шеврон справа.

## Правила

- Заголовок — настоящий `<button aria-expanded>` высотой от 64 px; панель — `id` + `aria-controls`. Разделители `line` сверху и снизу каждой строки.
- Шеврон в круге 32 px: закрыт — рамка `line`, открыт — заливка `brand`, иконка повёрнута на 180°. Раскрытие 200 мс, без «пружины».
- Программа: над заголовком дня — `q-acc__meta` прописными `accent-ink` («День 1 · 8 декабря»). Внутри — строки `q-sched`: время 64 px слева (`q-num`), название и одна строка пояснения. Пока время не утверждено — «—:—», а над списком примечание «Время уточняется».
- Первый день программы открыт по умолчанию; в FAQ открыт первый вопрос. Можно открыть несколько строк одновременно.
- FAQ: 8–10 вопросов. Ответ — 1–3 предложения, ссылки внутри — `q-link`. Длинный ответ (> 600 знаков) — признак того, что вопрос нужно разбить.
- При переходе по якорю `#faq-<номер>` строка раскрывается.

## Что передаёт потребитель

Программа: `event.program[]` (`date`, `title`, `items[]`: `time`, `title`, `description`) и `program.note`. FAQ: `faq.items[]` (`question`, `answer`).
