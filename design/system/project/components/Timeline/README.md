# Timeline

Вехи ассоциации 2012 → 2026 как числовая прямая: сплошная линия `brand` для лет работы, пунктир для паузы, золотая точка — XII конкурс.

## Варианты

- **390** — `q-tl`: вертикальная ось слева, точка 24 px, справа период (20/26, 700, `brand`), заголовок и строка пояснения. Вся лента видна без прокрутки вбок.
- **1024+** — `q-tlh` (`--tl-cols` = число вех): горизонтальная ось сверху, точки на оси, подписи под ними. Если вех больше 5 — горизонтальная прокрутка с привязкой к вехам, стрелки `q-arrows` справа над осью.

## Состояния точки

| Класс | Вид | Когда |
|---|---|---|
| — | кольцо `brand` с точкой | обычная веха |
| `is-pause` | пунктирное кольцо `line-strong`, пунктирная линия до следующей вехи, период `ink-muted` | 2023–2026 |
| `is-now` | заливка `accent`, рамка `accent-ink`, центр `brand` | Декабрь 2026, XII конкурс |

## Правила

- Только вехи из ТЗ: 2012 — основание и первый конкурс; 2012–2023 — 11 международных, ~130 городских и областных, ~40 онлайн-конкурсов, более 10 000 учителей; 2023–2026 — пауза; декабрь 2026 — XII конкурс, Алматы. Новые вехи добавляет команда в админке.
- Появление при прокрутке: линия «прорисовывается» слева направо (или сверху вниз) за 600 мс, точки проявляются по очереди с шагом 80 мс. `prefers-reduced-motion` — без анимации.
- Рядом с таймлайном — инфографика цифр (`Stat`) и призы прошлых лет; см. макет блока 7.

## Что передаёт потребитель

`history.milestones[]`: `period`, `title`, `text`; признак паузы / текущего конкурса вычисляется по порядку или задаётся отдельным полем (предложение для админки).
