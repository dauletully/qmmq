# FormField

Поля трёх форм лендинга (регистрация, заявка от школы, положение): подпись над полем, поле 52 px, подсказка или ошибка под ним.

## Состав

| Класс | Что |
|---|---|
| `q-field` > `q-label` + поле + `q-hint` / `q-error` | Любое поле. Подпись всегда видима — плейсхолдер её не заменяет. |
| `q-input` | Текст, e-mail, число. 16 px — иначе iOS увеличивает страницу при фокусе. |
| `q-select` > `select.q-input` + `q-select__chev` | Предмет, регион, стаж, «Как узнали». Нативный `select`: на телефоне открывается системный список. |
| `q-phone` | Телефон WhatsApp: неизменяемый префикс «+7» и маска `(XXX) XXX-XX-XX`, `inputmode="tel"`. Вставка «8 701…» или «+7 701…» нормализуется. |
| `q-chips` > `q-chip` | Множественный выбор предметов в заявке от школы; выбранный — `is-selected` + галочка. |
| `q-check` | Согласие с офертой и обработкой данных: квадрат 24 px внутри строки высотой ≥ 44 px, ссылки — `q-link`. |
| `q-summary` | Сводка ошибок над формой после отправки: число полей и ссылки-якоря к ним, `role="alert"`. |
| `q-note` | Информационная плашка `brand-tint`: «Менеджер перезвонит в рабочее время». |

## Состояния

- Фокус — рамка `brand` + `focus-ring`.
- Ошибка — рамка 2 px `error`, под полем `q-error` с иконкой `circle-alert`: что исправить, а не «Неверный ввод». Цвет никогда не единственный признак.
- Отключённое — `surface-disabled`, текст `ink-muted`. Пример: «Город» недоступен, пока не выбран регион.
- Отправка — главная кнопка `disabled` с текстом «Отправляем…».

## Тексты ошибок (ключи из API → текст на клиенте)

`required` — «Заполните это поле» · `full_name` — «Укажите фамилию и имя полностью» · `invalid_phone` — «Введите 10 цифр номера после +7» · `invalid_email` — «Проверьте адрес: в нём должны быть @ и домен» · `consent` — «Без согласия мы не сможем принять заявку» · `rate_limited` — «Слишком много попыток. Попробуйте через минуту».

## Правила

- Обязательные поля — красная звёздочка `*` (`aria-hidden`) и `required` на поле; над формой строка «* — обязательные поля». Необязательные можно пометить «(необязательно)» в `q-opt`.
- Валидация при уходе из поля и при отправке; при отправке фокус переходит на `q-summary`.
- Вертикальный шаг между полями 20 px (`space-5`).
