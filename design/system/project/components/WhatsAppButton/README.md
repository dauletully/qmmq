# WhatsAppButton

Круглая плавающая кнопка 56 px справа внизу на мобильных — ссылка `wa.me` на номер из настроек сайта.

## Правила

- Цвет `whatsapp` (#128C7E), иконка белая (`on-brand`), 28 px; белое кольцо 2 px (`surface`) и тень `shadow-fab`. Белая иконка — 4.1:1. Кольцо нужно варианту B: без него край кнопки на зелёном `brand` — 2.93:1 (ниже 3:1); с кольцом — 12:1 и больше на любом фоне.
- В макете — линейная иконка Lucide `message-circle`. В вёрстке её можно заменить официальным глифом WhatsApp из бренд-ресурсов Meta; нарисованную «по памяти» эмблему не использовать.
- Положение: `right: 16px`; `bottom: 16px`, а когда видна `StickyBar` — `bottom: sticky-bar-h + 16px` (плавно, 150 мс).
- `aria-label="Написать в WhatsApp"`, событие аналитики `whatsapp_click`.
- На десктопе кнопки нет: WhatsApp — в шапке контактов (блок 12) и в подвале.

## Что передаёт потребитель

Номер WhatsApp из `site-settings` и, по желанию, заготовку сообщения (`?text=`) на языке страницы.
