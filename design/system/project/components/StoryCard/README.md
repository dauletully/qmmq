# StoryCard

История учителя, выросшего до тренера призёров: цитата, предмет и олимпиада, затем человек — фото, имя, школа, год первого участия.

## Правила

- Белая карточка, рамка `line`, радиус `radius-md`, отступ 24 px, ширина 316 px в карусели на 390.
- Кавычка — иконка Lucide `quote` 28 px цвета `accent-ink`. Цитата 18/28 `ink`, 2–4 фразы (до ~320 знаков). Без курсива: у Golos Text нет настоящего курсива.
- Теги: предмет (`q-tag--math` и т. п.) и олимпиада учеников (`q-tag--outline`: IMO, IPhO, IOI, Жаутыковская олимпиада).
- Подпись: квадратное фото 56 px с той же ч/б обработкой, что у спикеров; имя 16/22 600; «Школа, город · участник с 2014 года» — `ink-muted`.
- Цитаты, имена и школы — только реальные, с согласием на публикацию (`publishConsent`). До этого — заглушка `is-placeholder`: текст-описание приглушён, «Имя Фамилия», «участник с 20__ года».

## Раскладка

390 — карусель `q-carousel` + `q-dots`, после неё главная кнопка `data-cta="stories"`. 1024+ — 3 карточки в ряд (4-я уходит в карусель со стрелками).

## Что передаёт потребитель

`stories.items[]`: `person` (→ `people`: `name`, `photo`, `school`, `firstParticipationYear`, `subjects`), `quote`, `achievement`.
