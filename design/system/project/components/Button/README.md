# Button

Три вида кнопок: главная (золото, одна на экран), второстепенная (контур) и текстовая; все не ниже 44 px.

## Классы

| Класс | Где |
|---|---|
| `q-btn q-btn--primary` | «Зарегистрироваться — 50 000 ₸», «Отправить заявку». Заливка `accent`, текст `on-accent` (= `brand`), наведение `accent-hover`. Не больше одной на экран, плюс закреплённая панель на мобильных. |
| `q-btn q-btn--secondary` | «Скачать положение», «Заявка от школы» рядом с главной. На светлом — рамка `line-strong`, текст `brand`; внутри `.q-dark` — рамка `on-brand-muted`, текст `on-brand`. |
| `q-btn q-btn--brand` | Тёмная заливка для «Записаться в лист ожидания» и кнопок на `accent-tint`. |
| `q-btn q-btn--text` | Ссылки-действия: «Скачать программу (PDF)», «Все вопросы». Подчёркнуты, зона касания 44 px. |
| `q-btn--sm` | Шапка десктопа: 44 px, 15 px текст. |
| `q-btn--block` | На мобильных главные кнопки во всю ширину колонки. |

## Правила

- Глагол первым, без восклицательных знаков: «Зарегистрироваться», «Скачать положение», «Отправить заявку».
- Цена в главной кнопке — через тире с разреженным `q-btn__sep`: `Зарегистрироваться — 50 000 ₸`; неразрывные пробелы в «50&nbsp;000&nbsp;₸».
- Белый текст на золоте запрещён (2.4:1). Золотая кнопка на белом допустима: её опознаёт подпись (5.8:1 к заливке).
- Отключённая (`disabled`): `surface-disabled` + `ink-muted`, только на время отправки формы — с текстом «Отправляем…».
- Фокус: `focus-ring` на светлом, `focus-ring-on-brand` внутри `.q-dark`.
- Иконка Lucide 20 px слева от текста (`download` у положения), `gap` 8 px.

## Что передаёт потребитель

Текст (из полей `primaryCta` / `secondaryCta` вкладки `hero`), `href` или обработчик, `data-cta="hero|header|pricing|stories|final|sticky"` для аналитики.
