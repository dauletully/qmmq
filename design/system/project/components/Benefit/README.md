# Benefit

Пункт выгоды: линейная иконка Lucide в плашке 48 px, заголовок и одно предложение. Без фото.

## Правила

- Плашка `brand-tint`, иконка `brand`, 24 px, линия 1.5, без заливок.
- 390: `q-benefit` — иконка слева, текст справа, пункты разделены линией `line`. 1024+: `q-benefit--stack` — иконка над текстом, сетка 3 × 2.
- Заголовок — `q-benefit__title` (18/24, 600), до ~40 знаков; текст — одно предложение до ~110 знаков.
- Набор иконок для шести выгод из ТЗ: `file-badge` (документ), `hourglass` (4–6 часов задач), `messages-square` (разбор с тренерами), `graduation-cap` (встречи с учёными), `users` (сообщество), `trophy` (призы).
- Иконка выбирается в админке из списка имён Lucide (поле `icon`); при неизвестном имени — `circle-check`.

## Что передаёт потребитель

`benefits.items[]`: `icon`, `title`, `text`.
