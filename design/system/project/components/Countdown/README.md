# Countdown

Остаток времени до `event.registrationDeadline` в днях, часах и минутах; после дедлайна заменяется состоянием «Лист ожидания».

## Варианты

| Вариант | Классы | Где |
|---|---|---|
| Панель | `q-countdown` + `q-countdown__cells` (3 ячейки) | Первый экран 1024+, блок стоимости |
| Строка | `q-countdown q-countdown--inline` | Первый экран 390, закреплённая панель |
| Лист ожидания | `q-waitlist` + главная кнопка «Записаться в лист ожидания» | Вместо счётчика после дедлайна, на всех местах сразу |

## Правила

- Только дни, часы, минуты — без секунд: академичный тон, не распродажа. Обновление раз в минуту.
- Цифры `q-num` (табличные), на `brand` — `on-brand` в ячейках `brand-raised`; в строке на тёмном — `accent`.
- Склонение единиц по числу: 1 день / 2 дня / 5 дней; 1 час / 2 часа / 5 часов; 1 минута / 2 минуты / 5 минут. Казахский: күн, сағат, минут (не склоняются).
- Меньше суток — показывать «14 ч 32 мин» без «0 дней».
- `role="timer"`, `aria-live="off"`; рядом обычным текстом дата: «Регистрация до 30 ноября» — из `deadlineNote` (дата в макетах — заглушка).
- Значения 27 / 14 / 32 в макетах условные.
- Лист ожидания: статус прописными `accent` + иконка `calendar-clock`, текст `on-brand-muted`; форма та же, заявка сохраняется с типом `waitlist`.
