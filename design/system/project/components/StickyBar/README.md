# StickyBar

Закреплённая снизу панель на мобильных (< 1024): главная кнопка «Зарегистрироваться — 50 000 ₸» и строка с оставшимся временем.

## Поведение

- Появляется, когда главная кнопка первого экрана уходит из зоны видимости; скрывается, пока на экране форма регистрации (блок 5) и пока открыта клавиатура.
- Высота 76 px + `env(safe-area-inset-bottom)`; фон `surface`, тень `shadow-sticky`. Под панелью у страницы нижний отступ `sticky-bar-h`, чтобы подвал не перекрывался.
- Кнопка во всю ширину, `data-cta="sticky"`. Нажатие прокручивает к форме блока 5 (не открывает отдельное окно).
- Строка над кнопкой: слева «До конца регистрации», справа остаток в формате «27 дн 14 ч 32 мин» (`q-num`, без секунд — не мельтешит).
- После `registrationDeadline`: слева «Приём заявок завершён», справа «Лист ожидания», кнопка `q-btn--brand` «Записаться в лист ожидания».

## Что передаёт потребитель

Цену (`event.price`), дедлайн (`event.registrationDeadline`), подписи на текущем языке.
