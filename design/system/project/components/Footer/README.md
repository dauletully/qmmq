# Footer

Подвал на `brand-deep`: знак и название ассоциации, контакты, документы, реквизиты одной строкой.

## Правила

- Заголовки колонок — прописные 13 px `accent` (7.1:1 на `brand-deep`), ссылки — `on-brand`, пояснения — `on-brand-muted` (9.9:1).
- 390: колонки одна под другой, зазор 32 px; нижний отступ увеличен на `sticky-bar-h`, чтобы закреплённая панель не закрывала реквизиты. 1024+: три колонки.
- Реквизиты, телефон, e-mail, адрес и документы берутся из `site-settings`; в макетах это заглушки («+7 (000) 000-00-00», «name@qmmq.kz»).
- Без соцсетей-иконок брендов: ссылки текстом («Instagram», «Канал сообщества»), пока не утверждён список.
