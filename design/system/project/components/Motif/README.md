# Motif

Единственный графический мотив: координатная сетка («миллиметровка») и первое предложение «Начал» Евклида — построение равностороннего треугольника на отрезке AB двумя окружностями.

## Почему он

Это самое первое построение в истории математики как дисциплины: из двух точек циркулем и линейкой получается фигура с доказанным свойством. Мотив говорит «основа, строгость, доказательство», а не «праздник». Он не иллюстрирует физику и информатику напрямую — и не должен: это знак сообщества, а не предмета.

## Правила

- Сетка: `q-grid-bg` (шаг 32 px, линии `grid-on-brand`) — только на `brand`: первый экран, лента обращения. На светлом — `q-grid-bg--light`, только на странице «Спасибо» и в заглушках портретов.
- Построение — инлайновый SVG `viewBox="0 0 480 400"`: окружности `q-construct--faint`, треугольник, засечки равенства сторон и дуга угла — `q-construct` (`accent`), точки 3.5 px, подписи A, B, C — 13 px `on-brand-muted`. Линии 1 px, `vector-effect: non-scaling-stroke` — толщина не меняется при масштабе.
- Позиция: 390 — правый верхний угол первого экрана, частично за краем, под заголовком; 1440 — правая колонка первого экрана целиком, ~560 × 470.
- Анимация появления (по желанию): окружности прорисовываются за 900 мс (`stroke-dashoffset`), затем треугольник за 400 мс. `prefers-reduced-motion` — сразу готовый рисунок.
- Не делать: заливки фигур, градиенты, формулы-«обои», больше одного построения на экран, мотив под мелким текстом.
- `aria-hidden="true"` — декор.
