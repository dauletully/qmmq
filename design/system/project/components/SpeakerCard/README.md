# SpeakerCard

Карточка спикера или члена жюри: квадратный портрет, роль, имя, регалии и одна строка о вкладе.

## Портрет

- Квадрат 1:1, радиус `radius-md`, `object-fit: cover`, `object-position: 50% 30%`.
- Одинаковая обработка для всех: чёрно-белое (`grayscale(1)`, контраст +5 %), однотонный светлый фон, глаза на ~40 % высоты, плечи в кадре. Цветные и групповые фото не ставить.
- Нет фото — `q-placeholder`: светлая координатная сетка `grid-on-surface` и инициалы `brand` 44 px (или иконка `user`, если имя ещё не известно). Подпись «Фото будет добавлено» — `ink-muted`, 12 px. Заглушка выглядит законченно и может жить на сайте.

## Текст

- Роль — тег: `q-tag--accent` «Спикер», `q-tag--outline` «Жюри».
- Имя — 18/24, 600. Регалии (`position`) — 15/22 `ink-secondary`, до двух строк. Вклад (`contribution`) — 14/20 `ink-muted`, одна-две строки.
- Порядок задаётся вручную; первым — академик Аскар Джумадильдаев.

## Раскладка

390 — карусель `q-carousel` (карточка 264 px, видно край следующей), под ней `q-dots`. 1024+ — сетка 4 колонки; больше восьми — карусель со стрелками `q-arrows`.

## Что передаёт потребитель

`speakers.people[]` → `people`: `name`, `photo`, `roles`, `position`, `contribution`; без `publishConsent` карточка не выводится.
