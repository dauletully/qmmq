# SubjectTag

Короткая метка предмета или роли: 28 px высотой, радиус `radius-xs`, 13 px полужирным.

## Варианты

- `q-tag--math` / `q-tag--physics` / `q-tag--informatics` — цвет `subject-*` на `subject-*-tint` (≥ 5.6:1) и иконка Lucide 14 px: `sigma`, `atom`, `code-xml`. Цвет никогда не единственный признак: в теге всегда название предмета.
- `q-tag--accent` — роль «Спикер» на карточке спикера.
- `q-tag--outline` — нейтральные метки: «Жюри», названия олимпиад в историях (IMO, IPhO, IOI, Жаутыковская олимпиада).

## Правила

Одно-два слова, с прописной, без точки. Казахские названия: Математика, Физика, Информатика (совпадают), роли — «Спикер», «Қазылар алқасы».

## Что передаёт потребитель

`subject` (`math` | `physics` | `informatics` из `lib/constants.ts`) или текст метки.
