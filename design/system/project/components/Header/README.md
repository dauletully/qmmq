# Header

Шапка на `brand`, закреплена сверху: временный текстовый знак «QMMQ», меню-якоря, переключатель RU/KZ, на десктопе — компактная главная кнопка.

## Раскладка

- **390** (`q-header q-dark`, 56 px): знак `q-mark` · пустое место · `q-lang` · кнопка меню `q-iconbtn` (иконка Lucide `menu`, `aria-label="Меню"`). Кнопки регистрации в шапке нет — её роль выполняет закреплённая снизу панель.
- **1024+** (`q-header--desktop`, 72 px): `q-brandline` (знак + название ассоциации в две строки) · `q-header__nav` · `q-lang` · `q-btn--primary q-btn--sm` с `data-cta="header"`. На 1024 название ассоциации скрывается, остаётся знак.
- Меню на 390 открывается полноэкранным листом на `brand`: якоря столбиком по 56 px, внизу RU/KZ и главная кнопка.

## Правила

- Логотипа пока нет: знак — слово «QMMQ» прописными в рамке 1.5 px. Не рисовать эмблему; когда появится логотип, он заменит `q-mark` целиком.
- Якоря: О конкурсе · Программа · Спикеры · Стоимость · FAQ · Контакты. Активный пункт (раздел в зоне видимости) — `on-brand`, остальные — `on-brand-muted`.
- `q-lang`: текущий язык — `aria-current="true"`, белая плашка. Переключение сохраняет позицию: ссылка ведёт на тот же якорь в `/kz`.
- Шапка не прячется при прокрутке вниз: в Instagram- и WhatsApp-браузерах поверх неё и так есть панель приложения.

## Что передаёт потребитель

Название ассоциации (`site-settings`), пункты меню с якорями блоков, текущую локаль и ссылку на другую, текст кнопки.
