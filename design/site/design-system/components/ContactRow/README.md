# ContactRow

Строка контакта с иконкой, подписью и значением — и заглушка карты, которая загружается только по нажатию.

## Варианты

- `q-contact` — сетка 44 px · текст: `q-contact__icon` на `brand-tint` (`phone`, `message-circle`, `mail`, `map-pin`, `clock`), `q-contact__label` 13 px `ink-muted`, `q-contact__value` 16/22 600. Телефон и e-mail — ссылки `tel:` / `mailto:`, WhatsApp — `wa.me` с событием `whatsapp_click`.
- `q-map` — плашка на сетке `grid-on-surface` с кружком-пином `q-map__pin` и кнопкой «Показать карту»; высота 200 px на 390, 420 на 1440. После нажатия на её место встаёт карта (iframe 2ГИС / Яндекс по `mapUrl`).
- На 1440 контакты — 5 колонок слева, карта — 6 колонок справа (`q-cols--5-7`).

## Правила

- Значения берутся из `site-settings` и никогда не пишутся в тексте страницы; заглушки в макетах — «+7 (000) 000-00-00», «name@qmmq.kz».
- Разделители `line` между строками; строка не ниже 68 px — вся она кликабельна.
- Карта не грузится до нажатия: LCP во встроенном браузере Instagram важнее удобства одного клика.
- Рядом с адресом — «Как добраться» в одну строку, если площадка известна.

## Что передаёт потребитель

`site-settings`: `phones[]`, `whatsapp`, `email`, `address` *loc*, предлагаемые `workHours` *loc* и `mapUrl`; для мероприятия — `events.venue`, `venueAddress`, `mapUrl`.
