# Pagination

Постраничная навигация списков (новости, архив, каталог людей) и кнопка «Показать ещё» для лент на телефоне.

## Варианты

- `q-pager` — `<nav aria-label="Страницы">` > `<ul>`: стрелки `q-pager__arrow` (44 px, рамка `line-strong`; недоступная — `is-disabled`, рамка `line`), номера 44 px, текущая — `aria-current="page"`, заливка `brand`; пропуск — `q-pager__gap` «…».
- `q-loadmore` — второстепенная кнопка «Показать ещё 12» и строка `q-small` «Показано 12 из 48»; для каталога мероприятий и материалов на 390.

## Правила

- На 390 — не больше 5 номеров: первая, текущая ± 1, последняя; на 1440 — до 7.
- Страница — в URL (`?page=3`), чтобы кнопка «Назад» и ссылки работали; «Показать ещё» дописывает `?page=` без перезагрузки и сохраняет позицию.
- Фильтры и пагинация живут вместе: смена фильтра сбрасывает на первую страницу.
- По 12 карточек на страницу (на 1440 ровно 4 ряда по 3).

## Что передаёт потребитель

`totalPages`, `page`, базовый URL с текущими фильтрами.
