# Gallery

Фотогалерея итогов и новостей: сетка 4:3 с подписью «что · где · год» под каждым кадром.

## Варианты

- `q-gallery` — 2 в ряд на 390, 4 на 1440 (`q-gallery--3` — три, когда кадров 3 или 6).
- `q-gallery__item--wide` — кадр на две колонки с пропорцией 16:9: первый, главный снимок события.
- По нажатию — просмотр на весь экран с подписью и стрелками; на телефоне — свайп. Без автопрокрутки.

## Правила

- Только реальные фото мероприятий с правами ассоциации или организаторов; снимки СМИ — по разрешению и с указанием автора в подписи.
- Подпись `q-gallery__cap` 13/18 `ink-muted` по формуле IMO: «Награждение · НАН РК, Алматы · 27 октября 2026». Без подписи кадр не публикуется.
- До загрузки — `q-placeholder` с иконкой `image` и `q-ph-note` «Фото: …», если кадр уже известен.
- Изображения `card` 800 (сетка) и `hero` 1600 (просмотр), WebP, ленивая загрузка, `alt` = подпись.

## Что передаёт потребитель

`media` с `alt` *loc* и предлагаемым полем `caption` *loc*; массивы `events.results.photos[]` и `news.gallery[]`.
