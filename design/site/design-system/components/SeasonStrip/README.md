# SeasonStrip

Лента сезонов конкурса учителей: кнопки-годы `q-years` для переключения и карточки сезонов `q-season` с номером, местом и числом участников.

## Варианты

- `q-years` — ряд кнопок 56 px: номер конкурса жирным (`I` … `XII`) и год под ним; текущий — `aria-current="true"` (заливка `brand`), будущий сезон — `is-next` (пунктир, `accent-ink`). На 390 — горизонтальная прокрутка за поля, на 1440 — перенос строк.
- `q-season` — карточка: номер 32 px `brand`, название, `q-season__meta` «Алматы · 2–3 декабря 2023 · площадки …». Сезон без подтверждённых данных — `q-season--muted` (пунктир, `surface-alt`) с текстом «Данные уточняются».
- Сезоны ведут на `/contest/[год]`; текущий (XII) — на лендинг `contest.qmmq.kz`.

## Правила

- Нумерация и годы — только из `docs/research/facts.md`: I — 2013, VII — 2019, VIII — 2021, IX — 2022, X — 2023; II–VI и XI — `--muted`, пока заказчик не подтвердит.
- В карточке сезона — победители (WinnersTable), фото (Gallery), задачи (DocumentCard), пресс-релиз; чего нет — честная строка, а не пустой блок.
- Кнопки лет — настоящие ссылки; текущая выделена и цветом, и `aria-current`.

## Что передаёт потребитель

Предлагаемая коллекция `contest-seasons`: `number` (римская), `year`, `title` *loc*, `dates`, `city`, `venues[]`, `participants`, `winners[]`, `photos[]`, `materials[]`, `pressRelease`, `landing` (→ landings) для текущего.
