# Breadcrumbs

Хлебные крошки внутренних страниц: путь от главной до текущего раздела, разделитель — точка 4 px.

## Варианты

- На светлом — `q-crumbs`: ссылки `ink-secondary`, текущая страница `ink-muted` без ссылки.
- Внутри `.q-dark` (шапка страницы на `brand`) — ссылки и точки `on-brand-muted`.

## Правила

- `<nav aria-label="Вы здесь">` > `<ol class="q-crumbs">`; текущий элемент — `aria-current="page"`.
- Не больше трёх уровней: «Главная · Мероприятия · Название». Длинное название последнего уровня обрезается с многоточием на 390 (`text-overflow`), полный текст — в `h1` ниже.
- Зона касания ссылки — 28 px по высоте внутри строки; ссылки стоят в ряд с зазором 8 px, поэтому целиться в них легко; на 390 крошки — единственная навигация вверх, кроме меню.
- Размер 14/20; на 1440 тот же.

## Что передаёт потребитель

Массив `{label, href}` из маршрута; названия разделов — из словаря интерфейса, название сущности — `title` коллекции (`events`, `news`, `people`, `pages`).
