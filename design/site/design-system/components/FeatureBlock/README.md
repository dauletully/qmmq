# FeatureBlock

Блок одного человека: крупный квадратный портрет, цитата и короткая справка — для академика Аскара Джумадильдаева на странице «Об ассоциации» и для обращений руководства.

## Варианты

- `q-feature` — белая карточка с рамкой `line`: портрет сверху на 390, на 1440 — портрет на 4 колонки слева, текст на 7 справа (зазор 96 px).
- `q-feature--dark` — на `brand`: обращение президента или вице-президента; цитата белая, кавычка золотая.

## Правила

- Портрет `q-feature__photo` — квадрат, ч/б, до 320 px на 390, во всю колонку на 1440; без фото — `q-placeholder` с инициалами.
- Цитата `q-feature__quote` 20/30 (26/38 на 1440), вес 500, 2–4 фразы; кавычка — иконка `quote` в `q-story__mark` (`accent-ink` на светлом, `accent` на тёмном). Только подтверждённые цитаты с источником (например, слова академика на награждении 27.10.2026).
- Под цитатой — имя и регалии (`q-h3` + `q-body`), затем 2–3 строки «Связь с ассоциацией»: что именно человек сделал (председатель жюри I конкурса, пленарная сессия IX конкурса, ориентир олимпиад 2026).
- Никаких «почётный председатель» и прочих титулов без подтверждения в `docs/research/facts.md`.

## Что передаёт потребитель

`people` (`name`, `photo`, `position`, `contribution`) и rich text блока из `pages` (`academician.quote`, `academician.body`); обращение — `author` → people, `body`, `signature`.
