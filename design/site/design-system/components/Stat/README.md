# Stat

Крупная цифра с подписью над волосяной линией — главный носитель доверия на странице.

## Правила

- Значение — `stat-m` (44 px) / `stat-d` (72 px), вес 600, `q-num`. На `brand` — `accent` (5.8:1), на светлом — `brand`. Золото на белом не использовать никогда.
- Подпись — `on-brand-muted` / `ink-muted`, строчными, без точки. Единица измерения — в подписи («лет — с 2012 года»), не в цифре.
- 390: `q-stat--row` — цифра и подпись в строку, три строки одна под другой. 1024+: три столбца, `q-stat--lg`.
- `q-stat--md` (56 px) — для блоков на 1440, где три цифры стоят в узкой колонке (8 колонок и меньше, например «14 лет в цифрах» на главной сайта рядом с диаграммой): 72 px там не помещаются.
- Тильда для приблизительных значений: «~130», «~40»; плюс для «10 000+»; неразрывный пробел в тысячах.
- Анимация: при первом появлении в зоне видимости число растёт от 0 за 1200 мс (`ease-out`); «10 000+» досчитывает до 10 000 и затем показывает «+». При `prefers-reduced-motion` — сразу итоговое значение. Нули не мигают: ширина зафиксирована табличными цифрами.
- Все цифры должны совпадать с положением о конкурсе: 14 лет · 10 000+ учителей · 11 международных конкурсов (первый экран), ~130 и ~40 (блок 7).

## Что передаёт потребитель

`stats[]` из вкладки `hero` и `figures[]` из вкладки `history`: `value` (строка, как показывать) и `label`.
