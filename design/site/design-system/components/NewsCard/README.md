# NewsCard

Карточка новости: обложка 16:10, дата и тег, заголовок, при месте — одно предложение анонса.

## Варианты

- **Сетка** (`q-news`): три в ряд на 1440 (`q-cols--3`), столбиком на 390.
- **Строка** (`q-news--row`): квадратная миниатюра 112 px слева на 390 (главная, список), 280 px с пропорцией 16:10 на 1440.
- **Главная новость** (`q-news--feature`): первая в списке, заголовок 22/28 (28/34 на 1440), обложка на 7 колонок.

## Правила

- Обложка — только реальное фото; без фото — `q-placeholder` с иконкой `image` и подписью `q-ph-note` «Фото: что · где · дата», если кадр известен, но ещё не загружен.
- `q-news__meta`: дата в именительном падеже («27 октября 2026», `tabular-nums`) и один тег `q-tag--outline` (Итоги · Мероприятия · Конкурс · Сообщество · Материалы). Предметные теги здесь не используются — новости редко о «предмете».
- Заголовок — до 90 знаков, две-три строки; анонс `q-news__text` — одно предложение, до 160 знаков, в сетке на 1440 и в `--feature`.
- Вся карточка — ссылка; наведение — подчёркивание заголовка.

## Что передаёт потребитель

Предлагаемая коллекция `news`: `title` *loc*, `slug`, `publishedAt`, `cover` (→ media), `tags[]`, `excerpt` *loc*; на главной — три последних опубликованных.
