# PageHero

Шапка внутренней страницы: крошки, надзаголовок, `h1` и вводный абзац на синей ленте — или на светло-серой для разделов-каталогов.

## Варианты

- `q-pagehero` — на `brand` (`q-dark`): «Об ассоциации», «Конкурс учителей», «Сообщество», «Партнёрам», страница мероприятия. Внутри — `q-pagehero__in`: крошки → `q-overline` → `h1.q-h1.q-h1--page` → `q-lead`.
- `q-pagehero--light` — на `surface-alt`: каталоги («Мероприятия», «Новости», «Материалы», «Педагоги-мастера») и текстовые страницы, где сразу под шапкой идут фильтры или текст, и синяя лента была бы лишним весом.
- Со статусом: на странице мероприятия в `q-pagehero__in` над `h1` — теги предметов и `q-status--lg`.

## Правила

- Отступы 24 / 40 px на 390 и 32 / 64 px на 1440; на 1440 текст ограничен 840 px.
- `h1--page` 30/36 на 390 и 48/56 на 1440 — меньше первого экрана главной (32 / 60): это страница раздела, а не обложка.
- Один `h1` на страницу; надзаголовок — постоянная подпись раздела из словаря интерфейса.
- Фото в шапке не ставим: лица и кадры идут в теле страницы с подписями.

## Что передаёт потребитель

`title` и `lead` страницы (`pages`, `events.title`, `news.title`), крошки, для мероприятия — `subjects[]`, статус регистрации по датам `registrationDeadline` / `startDate` / `endDate`.
