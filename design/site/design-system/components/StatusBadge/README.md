# StatusBadge

Метка состояния регистрации: точка и короткая фраза с датой. Показывает статус, а не называет его («Регистрация до 30 ноября», а не «Открыто»).

## Варианты

| Класс | Цвета | Когда |
|---|---|---|
| `q-status--open` | `success` на `success-tint` (4.9:1) | регистрация идёт; текст — «Регистрация до {дата}» |
| `q-status--soon` | `brand` на `brand-tint` (11:1) | мероприятие объявлено, регистрации ещё нет — «Анонс» или «Регистрация с {дата}» |
| `q-status--waitlist` | `accent-ink` на `accent-tint` (5.7:1) | дедлайн прошёл, событие впереди — «Лист ожидания» |
| `q-status--closed` | `ink-muted` на `surface-alt` (5.3:1) | регистрация закрыта, мест нет — «Регистрация закрыта» |
| `q-status--past` | `ink-muted` на `surface-alt`, серая точка | событие прошло — «Итоги · {дата}» |

`q-status--lg` — 36 px для шапки страницы мероприятия. Внутри `.q-dark` фон — белый с прозрачностью, текст светлый (open — `#8fdcb0`, 8.6:1 на `brand`).

## Правила

- Статус вычисляется на сервере по `registrationDeadline`, `startDate`, `endDate` и лимиту мест; в карточке и в шапке мероприятия — один и тот же текст.
- Цвет никогда не единственный признак: у каждого варианта своя фраза; точка — `currentColor`.
- Высота 28 px, в одну строку, `white-space: nowrap`. В карточке стоит справа в подвале; в шапке страницы — под `h1`.
- Даты — «30 ноября» в полном контексте и «30 ноя» в тесной карточке на 390 (сокращения из словаря RU/KZ).

## Что передаёт потребитель

`events`: `registrationDeadline`, `startDate`, `endDate`; предлагаемые поля `registrationOpensAt` и `seatsLeft` (см. README сайта).
