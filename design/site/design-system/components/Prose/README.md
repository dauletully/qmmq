# Prose

Типографика длинного текста — новость, политика конфиденциальности, оферта, описание мероприятия — и оглавление страницы.

## Варианты

- `q-prose` — колонка до 720 px: абзацы 16/26 (18/30 на 1440), `h2` 22/28 `brand` (28/36), `h3` 18/24 (22/30), списки с отступом 22 px, ссылки `brand` с подчёркиванием, цитата с золотой линией слева на `surface-alt`, `figure` с подписью 13 px.
- `q-toc` — оглавление на `surface-alt`: заголовок прописными `q-toc__title` и ссылки на `h2`; на 390 стоит над текстом, на 1440 — в правой колонке (`q-cols--8-4`), `sticky`.
- Внутри rich text допустимы DocumentCard (приложенные файлы) и Gallery (кадры новости) — они не входят в `q-prose` и ставятся между блоками текста.

## Правила

- Один `h1` вне `q-prose` (в PageHero); в тексте — `h2` и `h3`, без пропуска уровней.
- Текстовая страница начинается со строки «Обновлено 1 октября 2026» (`q-small`) — для политики и оферты это обязательно.
- Таблицы в тексте (реквизиты) — `q-tablewrap`, чтобы на 390 прокручивались внутри, а не ломали страницу.
- Курсив не используется (у Golos Text его нет); выделение — полужирный 600.

## Что передаёт потребитель

Rich text из `news.body`, `pages.body`, `events.description`; оглавление собирается из `h2` при рендере.
