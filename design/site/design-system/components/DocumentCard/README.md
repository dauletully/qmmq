# DocumentCard

Строка-карточка документа или материала: иконка типа, название, метаданные (формат · размер · год), метка доступа и кнопка скачивания.

## Варианты

- `q-doc` — сетка 48 px · текст · 44 px: `q-doc__icon` (`file-text` для PDF, `--tasks` с `sigma` для задач с решениями, `--slides` с `presentation` для презентаций, `--video` с `play` для видео), `q-doc__title`, `q-doc__meta`, `q-doc__act` (`download` или `external-link`).
- `q-doc--locked` — материал с ограниченным доступом: действие серое, иконка `lock`; по нажатию — вход или форма вступления.
- Метки доступа `q-access`: `--open` «Открыто», `--participants` «Участникам» (иконка `lock`), `--members` «Сообществу».
- Список `q-docs`; на 1440 `q-docs--2` — две колонки для библиотеки.

## Правила

- Документы ассоциации (устав, свидетельство, реквизиты, благодарности) — всегда `--open`; положения конкурсов — открыты после регистрации на лендинге (сейчас форма «Скачать положение»).
- В `q-doc__meta` — формат, размер и год через точку; для видео — длительность.
- Скачивание — реальная ссылка на файл `media` с `download`; аналитика — событие `regulations_download` / `material_download`.
- Название до 70 знаков; длиннее — переносится на две строки, карточка растёт.

## Что передаёт потребитель

Предлагаемые коллекции `documents` (`title`, `file` → media, `kind`, `year`) и `materials` (`title`, `kind` `regulation | tasks | slides | video`, `file` / `url`, `event` → events, `subjects[]`, `access` `open | participants | members`).
