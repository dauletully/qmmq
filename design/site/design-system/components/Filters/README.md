# Filters

Фильтры каталогов (мероприятия, педагоги-мастера, материалы, архив): чипы предметов в трёх цветах, выпадающие списки для типа, формата, уровня, региона и года, поиск, строка выбранных фильтров.

## Варианты

- **390** — `q-filters`: сверху `q-filters__bar` с полем `q-search` и кнопкой `q-chip q-chip--filter` «Фильтры» со счётчиком `q-chip__n`; под ней `q-filters__scroll` — горизонтальная лента чипов предметов, уходящая за поля (отрицательные поля −20 px). Остальные фильтры открываются листом FilterSheet.
- **1440** — всё в одну-две строки: поиск 320 px, чипы предметов, `q-select--inline` для типа / формата / уровня / региона / года, справа `q-filters__count` «Найдено 24».
- **Выбранные** — `q-active`: чипы `q-active__chip` с крестиком и ссылка `q-active__reset` «Сбросить».

## Правила

- Чипы предметов — `q-chip--math|physics|informatics`: выбранный получает цвет предмета на подложке `*-tint` (≥ 5.6:1); в чипе всегда текст предмета, при желании иконка `sigma` / `atom` / `code-xml`.
- Фильтры применяются сразу, без кнопки «Применить» на 1440; на 390 — кнопкой в листе. Состояние — в URL (`?subject=math&year=2026`), чтобы ссылку можно было переслать директору.
- Счётчик обновляется после каждого изменения; при нуле результатов — текст «Ничего не нашлось» и ссылка сброса.
- Все цели ≥ 44 px (`q-chip` — `min-height: tap-min`, `q-select--inline` — 44).

## Что передаёт потребитель

Словари из `lib/constants.ts` (`SUBJECTS`, `EVENT_TYPES`, `EVENT_FORMATS`, `EVENT_LEVELS`, `REGIONS`), годы — из данных коллекции; текущие значения из URL.
