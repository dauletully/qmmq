# Subscribe

Призыв подписаться на рассылку и каналы: поле e-mail с кнопкой, строка согласия и ссылки на Telegram / WhatsApp. Синяя лента перед подвалом на каждой странице.

## Варианты

- Лента `q-section q-cta q-dark q-grid-bg` с `q-cta__in`: на 390 текст над формой, на 1440 — 7 колонок текста слева, 5 колонок формы справа.
- `q-subscribe` — поле `q-input` и `q-btn--primary` «Подписаться»: столбиком на 390, в строку на 1440. Внутри `.q-dark` поле на `brand-raised` с рамкой `on-brand-muted`.
- `q-social` — кнопки-ссылки с рамкой: «Канал в Telegram», «Канал в WhatsApp», Instagram; подписи текстом, без брендовых иконок (Lucide их не рисует) — иконка `message-circle` допустима как общая.

## Правила

- Один призыв на страницу, всегда в одном месте — перед подвалом; на лендинге конкурса его нет (там свой финальный призыв).
- Под полем — `q-hint` «Нажимая „Подписаться“, вы соглашаетесь с политикой конфиденциальности» со ссылкой; отдельного чекбокса нет (одно поле — одно действие).
- После отправки поле заменяется строкой `circle-check` «Проверьте почту — мы отправили письмо для подтверждения»; ошибка — `q-error` под полем.
- Текст без восклицаний: «Узнавайте о конкурсах первыми. Одно письмо в месяц».

## Что передаёт потребитель

Предлагаемая коллекция `subscribers` (`email`, `locale`, `confirmedAt`, `source`) через `POST /api/forms/subscribe`; ссылки каналов — `site-settings.socials[]`.
