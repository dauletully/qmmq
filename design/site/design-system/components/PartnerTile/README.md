# PartnerTile

Плитка партнёра или организатора: плашка логотипа слева, тип прописными, полное название и строка роли («Площадка IX конкурса, 2022»).

## Варианты

- `q-partner` в сетке `q-partners`: столбиком на 390, три в ряд на 1440 (`q-partners--4` — четыре, для коротких названий спонсоров).
- Со ссылкой `url` — плитка становится `<a>`, в углу стрелка; логотип монохромный, цветной при наведении.
- Без логотипа — нейтральный значок по типу: `landmark` (министерство, академия), `building` (управление, школа, спонсор), `graduation-cap` (вуз), `book-open` (методический центр), `newspaper` (СМИ). Государственный герб не используем.

## Правила

- Плашка логотипа 64 × 56 на 390, 96 × 72 на 1440; логотип вписан по высоте 40 / 48 px — одинаковая оптическая высота у всех.
- `q-partner__kind` — надпись из словаря `PARTNER_KINDS` (Министерство · Организатор · Партнёр · Вуз · Спонсор · СМИ), `accent-ink`.
- `q-partner__year` — одна строка о роли в конкретном году: это и есть «легитимность показана, а не названа».
- На странице «Партнёрам» плитки сгруппированы по типу; на главной — 6–8 самых значимых по `order`.

## Что передаёт потребитель

`partners`: `name`, `logo`, `url`, `kind`, `order`; предлагаемое поле `note` *loc* (роль и год) или связь `events[]` для автоматической строки «Площадка X конкурса, 2023».
