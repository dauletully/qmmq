# Tile

Плитка «иконка — заголовок — абзац» для блоков «Три причины», «Что даёт сообщество», «Форматы сотрудничества» и прочих списков из 3–6 одинаковых пунктов.

## Варианты

- `q-tile` — белая с рамкой `line`, отступ 24 px; `q-tile__icon` 48 px на `brand-tint`, `q-tile__title` 18/24 (20/26 на 1440), `q-tile__text` 15/22 (16/24).
- `q-tile--alt` — на `surface-alt` без рамки: когда плитки стоят на белом фоне секции.
- `q-tile--gold` — на `accent-tint`: одна акцентная плитка в ряду («Для школ и управлений», «Пакет спонсора»).
- `q-tile__foot` — прижатая книзу строка со ссылкой `q-more` или кнопкой.

## Правила

- На 390 столбиком, на 1440 — `q-cols--3` (или `--2`, `--4`); одинаковая высота за счёт `q-tile__foot` с `margin-top: auto`.
- Иконка — одна из Lucide, линейная, цвет `brand`; не повторять одну иконку в соседних плитках.
- Заголовок — одно-два слова или короткая фраза («Рост», «Среда», «Люди»); текст — до трёх строк на 1440.
- Заменяет `q-benefit` там, где пункты — карточки, а не строки с разделителями.

## Что передаёт потребитель

Массивы вида `items[]` (`icon`, `title` *loc*, `text` *loc*, `href`) из блоков `pages` — те же имена иконок, что в `BENEFIT_ICONS`.
