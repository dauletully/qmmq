# PersonCard

Карточка человека для команды, совета, жюри и каталога педагогов-мастеров: квадратный ч/б портрет, имя, роль, регион и предмет.

## Варианты

- `q-person` в сетке `q-people`: 2 в ряд на 390, 4 на 1440 (`q-people--3` — три, для команды из 3–6 человек).
- `q-person--row` — портрет 72 px слева, текст справа: список жюри внутри страницы мероприятия, автор новости, подпись под обращением.
- Для каталога сообщества под ролью — `q-person__tags`: тег предмета и `q-tag--outline` с регионом.

## Правила

- Портрет — те же правила, что у SpeakerCard: квадрат 1:1, `object-position: 50% 30%`, ч/б, одинаковая обработка. Без фото — `q-placeholder` с инициалами (`q-placeholder__initials--sm` 28 px в сетке 2 × 2 на 390).
- Имя 17/22 (18/24 на 1440), роль `ink-secondary` 14/20 — одна-две строки: «Президент ассоциации», «Учитель математики, РФМШ». `q-person__meta` 13/18 `ink-muted` — город и год вступления.
- Человек выводится только с `publishConsent`; имена, школы и регалии — из коллекции `people`, не из текста страницы.
- Вся карточка — ссылка на профиль, когда профиль есть (каталог); в блоке команды — не ссылка.

## Что передаёт потребитель

`people`: `name`, `photo`, `roles[]` (`team` | `speaker` | `jury` | `master`, предлагается добавить `board` и `teamPosition`), `position`, `subjects[]`, `region`, `school`, `publishConsent`, `order`.
