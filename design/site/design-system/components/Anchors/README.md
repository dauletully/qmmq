# Anchors

Полоса якорей по разделам длинной страницы (мероприятие: Описание · Программа · Спикеры · Стоимость · Итоги) и закреплённая карточка-сайдбар с ценой и кнопкой на 1440.

## Варианты

- `q-anchors` — строка ссылок 52 px с линией снизу; активный раздел — `is-active` (`brand`, линия 2 px). На 390 прокручивается по горизонтали за поля и закрепляется под шапкой; на 1440 стоит в начале контента.
- `q-aside` — карточка на 4 колонки справа (`q-cols--8-4`), `position: sticky; top: 96px`: `q-aside__price` 40 px `brand`, список `q-aside__rows` (даты, город и площадка, дедлайн регистрации, групповые условия — иконки `calendar`, `map-pin`, `clock`, `users`), главная кнопка «Зарегистрироваться — 50 000 ₸», второстепенная «Заявка от школы», ссылка «Скачать положение».
- `q-checks` — список «Что входит» с галочками `success`; `q-checks--no` — «Не входит» с серыми иконками.

## Правила

- Якоря — настоящие `href="#program"`, активный переключается по прокрутке (`IntersectionObserver`); при `prefers-reduced-motion` прокрутка без анимации.
- На 390 роль сайдбара выполняет закреплённая панель `q-sticky` с кнопкой и датой (как на лендинге), а сам блок цены стоит в теле страницы.
- После дедлайна кнопка — «Записаться в лист ожидания», после события карточка сменяется блоком «Итоги» с кнопками «Победители», «Фото», «Задачи».
- Числа — `q-num`; цена `events.price`, порог `groupMinSize`.

## Что передаёт потребитель

`events`: `price`, `groupMinSize`, `startDate`, `endDate`, `registrationDeadline`, `city`, `venue`, `format`, `regulationsPdf`; разделы страницы — по наличию данных (нет спикеров — нет якоря).
