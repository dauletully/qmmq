# Передача проекта: состояние на 30.10.2026

Что это: сайт Казахстанской ассоциации учителей математики (qmmq.kz) и лендинг XII конкурса учителей (contest.qmmq.kz, Алматы, декабрь 2026). Цель — 400 оплат по 50 000 ₸. Исходные ТЗ — в [tz-landing.md](tz-landing.md) (выжимка) и в [ARCHITECTURE.md](ARCHITECTURE.md) (решения и модель данных).

## Решения заказчика
- Онлайн-оплаты нет: заявка → amoCRM (новая воронка) → менеджер принимает оплату.
- Хостинг — Yandex Cloud Kazakhstan, деплой заказчик делает сам по [DEPLOY.md](DEPLOY.md). Git локальный/свой, без CI.
- Без Telegram-уведомлений и почты на домене. Аналитика своя, отчёты в админке; GA4 и Метрики нет; пиксели Meta и TikTok — ID вводятся в админке (пока не ставить).
- Палитра A «Синий и золото», шрифт Golos Text, mobile-first (~80 % трафика с телефонов).
- Формы только для Казахстана: регионы РК, телефон +7 7XX XXX XX XX.
- Весь контент лендинга редактирует команда ассоциации в админке.
- Цифры из ТЗ (11 международных, ~130 / ~40, 10 000+, премия ~5 млн ₸) заказчик подтвердил как верные, хотя источниками они не проверяются — см. [research/facts.md](research/facts.md).

## Что готово
- Лендинг по макету (RU/KZ), три формы, регистрация в два шага на телефоне, дедлайн датой, SEO, кеш со сбросом из админки.
- amoCRM: очередь отправки с повторами, вебхук «Оплачено», настройка из админки (раздел «Интеграции»). Реальной amoCRM не проверялось — только на имитации.
- Своя аналитика и отчёты в админке `/admin/analytics`.
- Бэкенд основного сайта: новости, материалы, документы, страницы, подписчики, формы сообщества, RSS, sitemap, локаль en для двух страниц.
- Деплой: Docker, Caddy, бэкапы, [DEPLOY.md](DEPLOY.md). Docker на машине разработки не стоял — сборка образа не запускалась.
- Макеты основного сайта (35 артбордов) — `design/site/`, дизайн-система QMMQ — `design/system/`.

3. Рекомендации 1, 2, 4, 5, 8, 9 из [research/design-references.md](research/design-references.md) — ждут данных от ассоциации.
4. Личный кабинет, сертификаты с QR, онлайн-оплата — вторая очередь (янв–фев 2027).

## Ждём от ассоциации
Даты конкурса и срок регистрации, площадка, контакты и реквизиты, оферта и политика, PDF положения и программа, ссылка на чат участников, условия для школ и состав цены, образец документа о квалификации, вычитка казахских текстов, вектор логотипа, команда и совет с фото, архив мероприятий, устав и документы. Одобрение Бахнуром Зиябековым текста обращения (в сиде — черновик).

## Тонкости
- Согласие академика Джумадильдаева подтверждено; официальный портрет НАН РК — права формально у академии, письменное подтверждение желательно.
- Герб Министерства на сайте не используем (госсимволы в рекламе).
- Фото в `src/seed/assets/` попадают в репозиторий; исходники заказчика (`contents/`) и `.env` — нет.
- Миграции: следующую создавать `pnpm payload migrate:create <имя>`; `20261029_214830_add_lead_steps` написана вручную без json-снимка.
- Локальный PostgreSQL — кластер в `.local/pgdata` (не в git); на новом ноутбуке подними свой и поставь `DATABASE_URL` в `.env`, затем `pnpm seed`.

## Запуск на новом ноутбуке
См. [README.md](../README.md). Нужны Node 24, pnpm 12, PostgreSQL 17. Затем `pnpm install`, создать `.env` из `.env.example`, `pnpm dev`, `pnpm seed`.
